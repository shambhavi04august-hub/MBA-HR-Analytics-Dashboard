# 📊 MBA HR Analytics Dashboard

## 📌 Repository Name

**`MBA-HR-Analytics-Dashboard`**

## 📝 Repository Description

**Excel-based HR Analytics Dashboard analyzing employee headcount, salary, bonus, age, department, city, gender, and performance ratings to generate data-driven workforce insights.**

---

# 🚀 Project Overview

The **MBA HR Analytics Dashboard** is an Excel-based HR analytics project designed to transform employee data into meaningful workforce insights.

The dashboard provides an interactive overview of:

* 👥 Employee headcount
* 💰 Average salary
* 🎁 Average bonus
* 🎂 Average employee age
* 🏢 Department-wise workforce analysis
* 📍 City-wise workforce analysis
* ⭐ Performance rating distribution
* 👨‍💼👩‍💼 Gender-wise workforce analysis

This project demonstrates how Excel can be used to analyze HR data and support data-driven workforce decisions.

---

# 🎯 Project Objectives

* Analyze the overall employee workforce
* Compare employee headcount across departments
* Analyze average salary and bonus by department
* Understand workforce distribution across cities
* Analyze performance ratings
* Compare male and female employee representation
* Identify salary differences across locations and departments
* Present HR metrics through a clear dashboard

| HR         |        18 | ₹82,039.61 | ₹14,218.78 |

| Marketing  |        16 | ₹69,112.13 | ₹16,490.75 |
| Sales      |        29 | ₹80,246.45 | ₹18,472.52 |
